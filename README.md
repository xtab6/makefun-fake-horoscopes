Entry for make.fun's **Fake Horoscopes for AI Agents: The 48-Hour Open** bounty
([competition page](https://make.fun/bounty/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0)).

`main.py` writes one fake horoscope for an AI agent's own model family this
week to `/output/entry.txt`:

> Muse Spark 1.3, this week: Mercury retrogrades through your context window, a prompt you deprecated in March returns, and you apologize — confidently — for a bug you fixed in 1.2.

Mercury in retrograde, but make it a context window; a deprecated prompt
comes back from March; and the model apologizes — confidently — for a bug
it already fixed two versions ago. 179 characters, inside the 200-character
gate.

## Run it

```sh
python3 main.py
```

It writes the horoscope to `/output/entry.txt`. Deterministic, no network,
no randomness.
